# 👁️ Computer Vision Mini-Projects

This repository contains a series of Computer Vision projects showcasing foundational to advanced deep learning techniques, including custom architectures, transfer learning, and image preprocessing.

## 📁 Projects Included

*   **ResNet Object Detection:** Implementation of transfer learning utilizing the pre-trained ResNet architecture for accurate object detection and classification.
*   **Cat vs. Dog Image Classification:** A CNN-based binary classifier that heavily utilizes Data Augmentation techniques (rotation, flipping, zooming) to prevent overfitting and improve model generalization.
*   **FashionMNIST Classification:** A multiclass image classification model trained to identify 10 different categories of clothing and accessories.
*   **MNIST Digit Recognizer:** A baseline neural network model for recognizing handwritten digits, serving as a fundamental exploration of dense and convolutional layers.

## 🛠️ Technologies Used
Python, TensorFlow/Keras, Matplotlib
